# Sensa Design System

### Ultra-Minimal Professional

---

# 1. Philosophy

Sensa is a quiet, highly organized communication interface.

The interface should feel:

- silent
- light
- precise
- structured
- effortless

We believe that complexity should be handled by the engine, while the interface remains an oasis of calm.

The visual identity comes from:

- intentional whitespace
- small, legible typography
- consistent alignment
- absolute restraint

---

# 2. Design Goals

## Single-Focus Sections

Every part of the interface should do one thing perfectly. No overloading. No noise.

## Scale & Proximity

Use small typography and generous whitespace to create a sense of luxury and professional focus.

## No Decoration

No italics. No mono fonts. No gradients. No unnecessary borders. Use space and subtle background shifts for organization.

---

# 3. Typography

## Font Stack

- Primary: Inter or SF Pro (Sans-serif only)
- **Zero Monospace**: No mono fonts in the UI.

## Typography Rules

- **Size**: Keep text small. 13px - 14px for body. 20px - 24px for main headings.
- **Style**: No italics. Use weight (400, 500, 600) for hierarchy.
- **Spacing**: Generous letter spacing (tracking) for uppercase labels.

| Element       | Size    | Weight | Tracking |
| ------------- | ------- | ------ | -------- |
| Main Heading  | 24–28px | 600    | -0.01em  |
| Section Title | 16–18px | 500    | 0        |
| Body          | 13–14px | 400    | 0        |
| Label         | 10–11px | 600    | 0.05em   |

---

# 4. Color System

| Role       | Color     |
| ---------- | --------- |
| Background | `#FFFFFF` |
| Surface    | `#F9F9F9` |
| Border     | `#EEEEEE` |
| Text       | `#111111` |
| Muted      | `#888888` |

---

# 5. Geometry

- **Radius**: `4px` or `6px` for a soft, professional feel.
- **Borders**: Thin (`1px`) and light (`#EEEEEE`).
- **Shadows**: Extremely subtle or non-existent. Prefer white space over shadows.

---
