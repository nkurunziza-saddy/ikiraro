04 / Inside Sensa

How it works — under the hood.

Everything runs on-device. The longest leg of the journey is 38 milliseconds. No screen contents ever leave your user's browser.

01
Input

Voice, keyboard, gaze, or switch. Sensa listens to whatever the user has.

Capture ~5 ms
02
Parse

Reads the rendered DOM, auto-detects landmarks, headings, forms, and product fields.

DOM scan ~12 ms
03
Intent

Whisper-tiny + a Sensa-trained intent model, running on WebGPU. Multilingual.

Inference ~38 ms
04
Action

Maps to a DOM element. Irreversible actions wait for a spoken "yes." Logs nothing.

Dispatch ~3 ms
05
Output

Neural TTS streams the response. Common phrases cached for instant playback.

Synthesis ~14 ms
72 ms, median. Every step on-device. Zero round-trips to a server.

11 / FAQ

Answered honestly.

Does Sensa send my users' data anywhere?
No. All speech recognition, TTS, and DOM analysis runs on-device in the browser using small ML models we ship in the SDK. The only thing that leaves the page is anonymous aggregate usage telemetry, which you can disable with one flag.
Is this a substitute for proper a11y in my own code?
No — and we wouldn't pretend otherwise. Sensa fills the gap between "we tried" and "we shipped", and the dashboard flags the issues only a human can fix. Most teams use both: ship Sensa on day one, then chip away at the underlying audit over the next quarter.
Will it slow down my site?
12 KB gzipped on first paint. Heavier modules (voice models, ASL avatar) download only when a user explicitly opens that feature. The median measured LCP impact is +18 ms.
How is voice shopping different from a regular chatbot?
Sensa operates the page itself — it scrolls, opens menus, fills fields, and clicks buttons, narrating each step. The user remains in control: every irreversible action (add to cart, submit payment) waits on a spoken "yes." No headless agent, no hidden purchases.
What about languages other than English?
38 languages for read-aloud and live captions. 14 for voice control. Sign language is currently English-only ASL with BSL in beta; we expect to add LSF and DGS in Q4.
