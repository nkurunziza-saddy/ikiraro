## Findings considered and rejected

Recorded so they are not re-audited next run:

- **`client.ts:164` "race condition / TypeError when runtime is null"** — false: `runtime?.getState().plugins[...]` short-circuits the entire chain when `runtime` is nullish; no TypeError is possible. By-design.
- **API keys in `apps/web/.env.local`** — gitignored (verified `git ls-files | grep .env` → empty), plaintext-on-disk dev keys are the standard convention; not a finding.
- **`WebSpeechProvider.setConfig()` AudioContext leak** — false: the `!this.audioContext` guard at `web-speech.ts:46` prevents re-creation.
- **README promising `IkiraroSDK.translateTextAsync` / `translateSpeechAsync`** — hallucinated by an audit subagent; the strings appear nowhere in the repo.
- **"Verify TypeScript 6 / zod 4 versions are intentional"** — zod is unused (removed by plan 010); TS 6 typechecks green; no action.
- **`evaluateHandGeometry` missing-landmark assertion (`vision/quality.ts`)** — already guarded (`length < 21` early return); adding assertions is churn.
- **Vision↔renderer backpressure contract / frame-drop counters** — MED-confidence smell with no observed failure; revisit only if frame drops are reported in practice.
- **Groq STT/gloss error-handling standardization** — real but minor inconsistency; deferred (would ride along with any future runtime test harness).
- **`sign-model-gltf.tsx` useFrame decomposition (332 lines)** — legitimate readability concern, but per-frame R3F code with no test harness; risk outweighs benefit until a renderer test/visual-regression story exists.
- **Audio accessibility subsystem tests** (direction) and **reference plugins** (direction) — acknowledged as valuable; not planned this round at maintainer's discretion. Re-raise after 008 establishes the runtime test pattern.
- **Design-system integration (untracked `apps/web/DESIGN.md`/`GEMINI.md`)** — direction finding; the active site redesign owns it. Note: those files are untracked — commit or relocate them or they may be lost.
